# Seven Tech Capital — واجهات UI/UX ولوحات التحكم

نموذج تفاعلي (Prototype) للموقع العام وبوابات المستثمر ورائد الأعمال ولوحة الإدارة،
مبني وفق وثيقة المتطلبات (BRD). المحتوى التشغيلي تمثيلي، مع نظام حسابات وجلسات PHP فعلي للتطوير المحلي.

## إدارة الصفحة الرئيسية

- افتح `backend/dashboard/admin-home.php` من قسم **المحتوى ← الصفحة الرئيسية** بحساب إدارة.
- ثمانية أقسام: المقدمة، الإحصائيات، المزايا، القطاعات، المسارات، قصص النجاح، المستجدات، والدعوة لاتخاذ إجراء.
- لكل قسم حقول محتوى وأزرار، وإظهار/إخفاء وترتيب. يمكن إضافة البطاقات وحذفها وتعديل الأيقونات ومؤشرات القصص ونوافذها.
- «حفظ ونشر القسم» يحدّث MySQL في جدول `home_page_sections` ويسجّل العملية في سجل التدقيق. لا يُستبدل المحتوى المعدّل عند إعادة تشغيل الخدمة.
- الصفحة العامة تقرأ `backend/api/home.php`. نسخة HTML على المنفذ `3000` تتصل بالمنفذ `8001` على اسم الجهاز نفسه، وتتحقق من التحديثات كل 15 ثانية. لا يحتاج الربط إلى تثبيت عنوان IP.
- يمكن ضبط `window.STC_API_BASE_URL` قبل تحميل `assets/js/api-config.js` عند تغيير عنوان الخادم.
- روابط القطاعات تستخدم مثلًا `sectors.php#sector-01`، وروابط الأخبار `news-events.php#news-CNT-001`؛ تُحوّل إلى صفحات HTML على الواجهة المنفصلة. تعديل بطاقات الرئيسية لا يغيّر المحتوى الأصلي في صفحات الأخبار والقطاعات.
- مع توقف MySQL لا يتم ادعاء نجاح الحفظ. تظل نسخة العرض الأولية في الواجهة الثابتة مع تنبيه واضح إلى تعذر تحميل المحتوى المحفوظ.
- الاختبارات: `tests/home-unit.php` و`tests/home-client.cjs` و`tests/home-role.php`. اختبار `tests/home-api.ps1` يستخدم `HOME_TEST_EMAIL` و`HOME_TEST_PASSWORD` مؤقتًا، ويعيد محتوى اختبار الحفظ إلى حالته الأصلية.

## تشغيل النسخة المحلية
عبر MAMP: ضع المجلد في `htdocs` وافتح:
```
http://localhost:8888/capital-ui/index.php
```
أو خادم PHP مباشر:
```
php -S 127.0.0.1:8000
```

يمكن إنشاء حسابات مستثمرين ورواد أعمال فعلية من صفحة الدخول. تُحفظ كلمات المرور بصورة مشفرة داخل MySQL.

## قاعدة بيانات MAMP

- قاعدة البيانات: `capital_ui`
- المضيف: `127.0.0.1`
- المنفذ: `3306`
- المستخدم: `root`
- كلمة المرور: `root`
- ملف الاستيراد: `database/capital_ui.sql`

يمكن استيراد الملف من phpMyAdmin، أو بالأمر:

```bash
/Applications/MAMP/Library/bin/mysql80/bin/mysql -h127.0.0.1 -P3306 -uroot -proot < database/capital_ui.sql
```

إعدادات الاتصال موجودة في `config/database.php`. يمكن تغييرها بمتغيرات
`DB_HOST` و`DB_PORT` و`DB_DATABASE` و`DB_USERNAME` و`DB_PASSWORD`.
إذا كانت MySQL متوقفة، يستخدم المشروع ملفات `storage/` مؤقتًا كحل احتياطي.

## إدارة صفحة من نحن

- من قسم المحتوى افتح `dashboard/admin-about.php`: سبعة أقسام في عمودين، وكل الأقسام والبطاقات مقفولة عند الدخول.
- عدّل النصوص والأيقونات والأزرار والبطاقات ثم اضغط «حفظ ونشر القسم». الترتيب والإظهار مستقلان للقسم ولكل بطاقة.
- يستخدم المحرر نفس عناصر التحرير الصغيرة الخاصة بالرئيسية. محتوى «من نحن» محفوظ في `about_page_items`، وإعدادات الأقسام في `about_page_sections`، دون نسخ محتوى الرئيسية.
- يقرأ الفرونت البيانات من `api/about.php` على الباك إند عبر إعداد العنوان المشترك، مع تحديث كل 30 ثانية. عند تعطل الاتصال يبقى آخر محتوى محمّل مع رسالة لإعادة المحاولة، ولا يتم عرض بيانات تجريبية بديلة.
- الحفظ محمي بصلاحية الإدارة وCSRF والتحقق من الروابط وإصدار القسم، ويُسجّل في سجل التدقيق. البطاقات القديمة الزائدة عن المحتوى المطلوب مخفية وقابلة لإعادة الإظهار من المحرر.
- اختبارات القسم: `tests/about-unit.php` و`tests/about-api.ps1` و`tests/about-client.cjs` و`tests/about-role.php`. اختبار API يستخدم متغيري `HOME_TEST_EMAIL` و`HOME_TEST_PASSWORD` ويعيد المحتوى الأصلي بعد الاختبار.

## المواصفات المطبّقة (من BRD)
- **الهوية**: برتقالي `#FF5000` كإشارة قرار، أسود `#111`، رمادي دافئ `#FAF7F3`، فحمي `#252525`.
- **الوضعان**: فاتح وداكن (زر التبديل في الشريط العلوي، محفوظ في localStorage).
- **RTL** كامل + مبدّل لغة (AR/EN/FR — العرض بالعربية في النموذج).
- **الخطوط**: Noto Kufi Arabic (عناوين) + Noto Sans Arabic (نصوص).
- **Mobile-first** + responsive + احترام `prefers-reduced-motion`.
- بوابات المراجعة، حالات KYC، خط مراجعة رواد الأعمال، سجل التدقيق، وقيود ما قبل الإطلاق المالي.

> ملاحظة: كل الأزرار الحسّاسة تعرض تنبيهًا توضيحيًا — الإجراء الفعلي يُنفَّذ عبر Angular + Laravel API في الإصدار الحي.
